# 뷰티 제품 런칭 상황판

뷰티 제품 아이디어를 모으고, 기획부터 생산까지 진행 상황을 추적하고, 경쟁 제품을 비교하는 웹 상황판입니다.
설치할 것도 서버도 필요 없습니다. `index.html` 을 더블클릭하면 브라우저에서 바로 열립니다.

## 메뉴 세 개

### 1. 아이디어 덤프

떠오른 제품 아이디어와 참고할 타사 사례를 아무렇게나 던져 두는 판입니다.

- **구분** — 내 아이디어 / 타사 레퍼런스 (카드에는 타사 레퍼런스일 때만 표시됩니다)
- **피부효능** — 미백 · 탄력 · 모공 · 결 · 트러블
- **카테고리** — 앰플 · 클렌저 · 크림 · 토너 · 마스크팩 · 바디
- **진행 상태** — 미정 · 보류 · 개발 진행
- **컨셉** — 어떤 고민을 어떻게 해결하는 제품인지
- **성분** — 핵심 성분과 함량
- **광고 소구점** — 광고에서 무엇을 어떻게 보여줄지
- **참고 레퍼런스** — 타사 제품, 아티클, 이미지 링크를 여러 개 붙일 수 있습니다
- **태그 · 메모**

피부효능과 카테고리는 각각 따로 걸러 볼 수 있습니다.

쓸 만해진 아이디어는 **`런칭 준비로 →`** 버튼 하나로 제품 런칭 상황보드에 넘어갑니다. 이때 아래 8단계 체크리스트가 자동으로 만들어집니다.

### 2. 제품 런칭 상황보드

제품마다 8단계를 따라갑니다. 각 단계에는 기본 체크리스트 6개가 들어 있고, **진행률은 체크한 항목 수에서 자동으로 계산됩니다.** 진행률을 손으로 입력하는 칸은 일부러 두지 않았습니다.

| # | 단계 | 무엇을 하는 단계인가 |
| --- | --- | --- |
| 1 | 제품 기획 | 무엇을, 누구에게, 왜 파는지 확정 |
| 2 | 제조사 미팅 | 만들어 줄 파트너를 찾고 조건을 맞춤 |
| 3 | 제형 확정 | 사용감과 전성분을 못 박고 상용화 가능한지 검증 |
| 4 | 임상 진행 | 광고에 쓸 효능을 숫자로 증명 |
| 5 | 제품 디자인 | 용기와 패키지 확정, 인쇄 발주 |
| 6 | 생산 | 본생산, 품질 검사, 입고 |
| 7 | 상세페이지 기획 | 고객을 설득할 문구와 구조 설계 |
| 8 | 비주얼 기획 | 제품이 보여질 이미지와 톤 제작 |

앞의 6단계는 물건을 만들어 내는 흐름이고, 뒤의 2단계는 그 물건을 파는 준비입니다.

8단계는 접히는 목록이 아니라 **각각 독립된 블록**으로 항상 펼쳐져 있습니다. 화면 폭에 따라 3열 → 2열 → 1열로 접힙니다.

**할 일 하나하나에 메모 칸이 붙어 있고 항상 보입니다.** 클릭해서 펼칠 필요가 없고, 내용이 길어지면 칸이 알아서 늘어납니다. 칸이 좁아지면 메모가 할 일 아래로 내려갑니다. 타이핑을 멈추면 저장됩니다.

각 단계마다 할 일을 추가·삭제할 수 있고, 단계 전체 메모와 목표일도 따로 남길 수 있습니다.
전체 목록 화면에서는 제품별 진행률과 8단계를 한 줄로 압축한 미니 지표를 함께 봅니다.

### 3. 경쟁 제품 리서치

런칭 준비 중인 제품별로 경쟁 상대를 모아 놓고 비교합니다.

- **가격 비교 차트** — 우리 목표 판매가를 경쟁 제품과 나란히 놓고 봅니다
- **비교 표** — 가격 · 용량 · 핵심 성분 · 소구 포인트 · 판매 채널 · 위협도 · 메모 · 링크

여기 쌓아 둔 내용은 7단계 상세페이지 기획에서 그대로 재료가 됩니다.

## 데이터는 어디에 저장되나요

입력한 내용은 **이 브라우저에만** 저장됩니다(localStorage). 서버로 전송되지 않고, GitHub에도 올라가지 않습니다.

그래서 이런 경우 내용이 사라집니다.

- 브라우저 데이터(쿠키 · 사이트 데이터)를 지웠을 때
- 다른 브라우저나 다른 PC에서 열었을 때
- 시크릿 모드에서 창을 닫았을 때

중요한 내용은 오른쪽 위 **`백업`** 으로 JSON 파일을 내려받아 두세요. 다른 PC에서는 **`불러오기`** 로 그 파일을 넣으면 그대로 복원됩니다.

## 파일 구성

```
index.html          화면 뼈대
style.css           디자인 (밝게 · 어둡게 자동 전환)
js/data.js          분류 기준, 8단계 정의, 초기 데이터
js/store.js         데이터 보관, 저장/복원, 진행률 계산
js/ui.js            공통 UI (진행률 막대, 상태 배지, 모달 폼)
js/ideas.js         1. 아이디어 덤프
js/pipeline.js      2. 제품 런칭 상황보드
js/competitors.js   3. 경쟁 제품 리서치
js/app.js           탭 전환, 테마, 백업
```

빌드 도구나 외부 라이브러리를 쓰지 않습니다. 파일을 고치고 저장한 뒤 브라우저를 새로고침하면 바로 반영됩니다.
