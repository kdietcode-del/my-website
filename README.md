# my-website

HTML / CSS / JavaScript 로 만든 간단한 웹사이트입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지의 구조와 내용 |
| `style.css` | 색상, 글꼴, 여백 등 디자인 |
| `script.js` | 버튼 클릭 같은 동작 |

## 실행 방법

`index.html` 파일을 더블클릭하면 브라우저에서 바로 열립니다.

## 수정한 내용을 GitHub에 올리기

```bash
git add .
git commit -m "변경 내용 설명"
git push
```
