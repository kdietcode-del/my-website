# 썸네일 가져오기 서버 설치하기

경쟁제품 참고보드에서 **상세페이지 링크만 넣으면 제품명 · 가격 · 썸네일이 자동으로 채워지게** 하는 작은 중계 서버입니다.

왜 필요한가요? 브라우저는 보안 규칙(CORS) 때문에 다른 사이트의 내용을 직접 읽지 못합니다. 그래서 중간에서 대신 읽어다 주는 역할이 필요합니다.

**돈은 들지 않습니다.** Cloudflare 무료 범위(하루 10만 건)로 충분합니다.

---

## 설치 — 브라우저에서 10분

### 1. Cloudflare 가입

https://dash.cloudflare.com/sign-up 에서 이메일로 가입합니다. 카드 등록은 필요 없습니다.

### 2. Worker 만들기

1. 왼쪽 메뉴에서 **Compute (Workers)** → **Create** 를 누릅니다
2. **Start with Hello World!** 를 고르고 **Get started**
3. 이름은 `thumbnail` 정도로 정하고 **Deploy**
4. 배포가 끝나면 **Edit code** (또는 **</> Edit code**) 를 누릅니다

### 3. 코드 붙여넣기

1. 편집기에 있던 내용을 **전부 지웁니다** (Ctrl+A → Delete)
2. 이 폴더의 [`thumbnail-worker.js`](thumbnail-worker.js) 내용을 **전부 복사해 붙여넣습니다**
3. 붙여넣은 코드 위쪽의 `ALLOWED_ORIGINS` 를 확인합니다. 본인 사이트 주소가 맞는지 보세요.

```js
const ALLOWED_ORIGINS = [
  "https://by.phb.kr",
  "https://kdietcode-del.github.io",
  "http://localhost:8765",
];
```

회원님 주소(`https://by.phb.kr`)는 이미 넣어 뒀습니다. 나중에 주소가 또 바뀌면 그때 한 줄 더 넣으면 됩니다.

4. 오른쪽 위 **Deploy** 를 누릅니다

### 4. 주소 복사

배포가 끝나면 이런 주소가 생깁니다.

```
https://thumbnail.<본인계정이름>.workers.dev
```

이 주소를 복사합니다.

### 5. 앱에 등록

1. 상황보드를 열고 오른쪽 위 **⚙ 설정** 을 누릅니다
2. **썸네일 가져오기 서버 주소** 칸에 복사한 주소를 붙여넣습니다
3. **저장**

끝입니다. 이제 경쟁제품 추가 화면에서 상세페이지 링크를 넣고 **`링크에서 가져오기`** 를 누르면 제품명 · 가격 · 썸네일이 채워집니다.

---

## 잘 안 될 때

| 증상 | 원인과 해결 |
| --- | --- |
| "허용되지 않은 주소에서의 요청입니다" | `ALLOWED_ORIGINS` 에 지금 쓰는 사이트 주소가 없습니다. 추가 후 다시 Deploy 하세요. |
| "봇 차단일 수 있습니다" | 그 사이트가 자동 접근을 막고 있습니다. 우회하지 않습니다 — 이미지 주소를 직접 붙여넣어 주세요. |
| 썸네일만 안 나옴 | 상세페이지에 대표 이미지 정보(og:image)가 없는 경우입니다. 직접 넣어야 합니다. |
| 가격이 이상함 | 본문에서 가장 자주 나온 금액을 고른 값이라 틀릴 수 있습니다. 확인하고 고쳐 주세요. |

## 사이트별로 다릅니다

확인된 결과입니다.

- **클럽클리오 등 자사몰** — 제품명 · 가격 · 썸네일 모두 잘 나옵니다
- **네이버 스마트스토어** — 확인하지 못했습니다. 봇 차단이 있을 수 있습니다
- **올리브영 · 쿠팡 등 대형 플랫폼** — 차단 가능성이 있습니다

**안 되는 사이트가 있어도 앱은 그대로 동작합니다.** 자동으로 못 가져오면 안내만 뜨고, 기존처럼 직접 입력하면 됩니다.

## 서버를 안 만들면?

앱은 문제없이 돌아갑니다. `링크에서 가져오기` 버튼을 누르면 "서버 주소가 설정되지 않았습니다" 안내가 뜰 뿐이고, 제품명 · 가격 · 이미지를 직접 입력하는 기존 방식은 그대로입니다.

# 키워드 검색량 켜기

컨셉보드 **시장크기** 칸에 키워드를 적고 칸을 빠져나오면, 지난 한 달 검색량이 저절로 채워지고 그 아래에 최근 6개월 추이가 작은 막대로 붙습니다.

이 기능은 **같은 워커**가 처리합니다. 새로 만들 것은 없고, 위 서버에 열쇠 다섯 개만 넣어 주면 됩니다.

블랙키위 계정은 연동할 수 없습니다. 외부에서 갖다 쓸 수 있는 창구를 열어 두지 않기 때문입니다. 대신 블랙키위가 보여 주는 숫자의 **원래 출처**인 네이버 쪽 창구를 직접 씁니다. 둘 다 무료입니다.

| 어디서 | 무엇을 | 열쇠 |
| --- | --- | --- |
| 네이버 **검색광고** | 지난 한 달 PC·모바일 검색수 | 3개 |
| 네이버 **개발자센터**(데이터랩) | 최근 6개월 검색 추이 | 2개 |

---

## 1. 네이버 검색광고 열쇠 3개

1. https://searchad.naver.com 에서 가입합니다. **광고를 집행하지 않아도 계정만 있으면 됩니다.**
2. 로그인한 뒤 오른쪽 위 **도구 → API 사용 관리** 로 들어갑니다
3. **네이버 검색광고 API 서비스 신청** 을 누르면 바로 발급됩니다
4. 화면에 뜨는 세 가지를 복사해 둡니다

| 화면에 적힌 이름 | 나중에 넣을 이름 |
| --- | --- |
| 고객 ID (6~8자리 숫자) | `NAVER_AD_CUSTOMER_ID` |
| 액세스 라이선스 | `NAVER_AD_API_KEY` |
| 비밀키 | `NAVER_AD_SECRET_KEY` |

비밀키는 **발급 때 한 번만** 보입니다. 놓치면 재발급하면 됩니다.

## 2. 네이버 개발자센터 열쇠 2개

1. https://developers.naver.com/apps/#/register 로 들어갑니다
2. **애플리케이션 이름** 은 아무거나 (예: `런칭보드`)
3. **사용 API** 에서 **데이터랩 (검색어트렌드)** 를 고릅니다
4. **환경 추가** 는 **WEB 설정** 을 고르고 서비스 URL 에 `https://by.phb.kr` 을 넣습니다
5. 등록하면 **Client ID** 와 **Client Secret** 이 나옵니다

| 화면에 적힌 이름 | 나중에 넣을 이름 |
| --- | --- |
| Client ID | `NAVER_CLIENT_ID` |
| Client Secret | `NAVER_CLIENT_SECRET` |

## 3. 워커에 열쇠 넣기

열쇠는 **보드 화면에 넣지 않습니다.** 그 파일은 누구나 볼 수 있습니다. 워커 안에만 넣어 두면 보드는 "검색량 알려 줘" 라고만 말하고, 열쇠는 워커가 들고 있습니다.

1. Cloudflare 대시보드에서 아까 만든 워커(`thumbnail`)를 엽니다
2. **Settings** → **Variables and Secrets** 로 갑니다
3. **+ Add** 를 눌러 아래 다섯 개를 하나씩 넣습니다. **Type 은 반드시 `Secret`** 으로 고르세요

```
NAVER_AD_CUSTOMER_ID
NAVER_AD_API_KEY
NAVER_AD_SECRET_KEY
NAVER_CLIENT_ID
NAVER_CLIENT_SECRET
```

4. 다 넣었으면 **Deploy** 를 눌러 다시 배포합니다

## 4. 코드도 새로 붙여넣기

검색량 기능이 들어간 새 코드입니다. 위 **설치 3번**과 똑같이, 편집기 내용을 전부 지우고 [`thumbnail-worker.js`](thumbnail-worker.js) 를 다시 붙여넣은 뒤 **Deploy** 하세요.

## 확인

```
https://thumbnail.<본인계정이름>.workers.dev/keyword?q=기미크림
```

주소창에 넣었을 때 `"total"` 에 숫자가 있으면 된 것입니다.

## 잘 안 될 때

| 증상 | 원인과 해결 |
| --- | --- |
| "네이버 열쇠가 아직 안 들어갔습니다" | 3번을 안 했거나, Deploy 를 다시 안 눌렀습니다. |
| "검색광고 API 가 401 를 돌려줬습니다" | 열쇠 세 개 중 하나가 틀렸습니다. 특히 비밀키를 앞뒤 공백 없이 붙여넣었는지 보세요. |
| "데이터랩 API 가 401 를 돌려줬습니다" | Client ID · Secret 이 틀렸거나, 그 애플리케이션에 **데이터랩** 을 안 붙였습니다. |
| 숫자는 나오는데 막대가 없음 | 데이터랩 열쇠만 빠진 경우입니다. 숫자는 검색광고에서 온 것이라 그대로 믿어도 됩니다. |
| 막대는 나오는데 숫자가 없음 | 검색광고에 그 키워드 기록이 없습니다. 검색량이 아주 적은 말입니다. |

## 숫자를 어디까지 믿나

- **검색량**(칸에 채워지는 숫자)은 네이버 검색광고가 주는 지난 한 달 실제값입니다. 블랙키위가 보여 주는 숫자와 같은 출처입니다.
- **막대 위에 뜨는 지난 달들의 숫자**는 추정입니다. 데이터랩은 비율만 주기 때문에, 마지막 달 비율을 실제값에 맞춰 놓고 나머지를 같은 배율로 편 값입니다. 오르는 추세인지 지는 추세인지 보는 용도로 쓰세요.
