# 공유 서버 만들기 — 모두가 같은 내용을 보게

지금은 입력한 내용이 **각자 브라우저에만** 남습니다. 그래서 주소를 공유해도 상대방은 빈 화면을 봅니다.

이 서버를 만들면 내용이 **한 곳에 한 벌만** 있게 되어, 누가 어느 기기에서 들어와도 같은 화면을 봅니다.

덤으로 **비밀번호가 진짜 인증으로 바뀝니다.** 지금은 브라우저 안에서 검사해서 우회가 가능하지만, 서버가 확인하면 우회할 수 없습니다.

**돈은 들지 않습니다.** Cloudflare 무료 범위로 충분합니다.

> 앞서 만든 썸네일 서버와는 **별개**입니다. 둘 다 있어야 각각의 기능이 돕니다.

---

## 1. KV 저장소 만들기

내용을 담아 둘 창고입니다.

1. https://dash.cloudflare.com 접속
2. 왼쪽 메뉴 **Storage & Databases** → **KV**
3. **Create instance** (또는 **Create a namespace**)
4. 이름: **`board`**
5. **Add**

## 2. Worker 만들기

1. 왼쪽 메뉴 **Compute (Workers)** → **Create**
2. **Start with Hello World!** → **Get started**
3. 이름: **`board`**
4. **Deploy**
5. **Edit code** 클릭

## 3. 코드 붙여넣기

1. 편집기 내용을 **전부 지웁니다** (Ctrl+A → Delete)
2. 이 폴더의 [`board-worker.js`](board-worker.js) 내용을 **전부 복사해 붙여넣습니다**
3. 오른쪽 위 **Deploy**

## 4. 저장소 연결

만든 창고를 Worker에 붙입니다. **이걸 안 하면 동작하지 않습니다.**

1. `board` Worker 화면에서 **Settings** 탭
2. **Bindings** → **Add** → **KV namespace**
3. 이렇게 넣습니다

| 칸 | 값 |
| --- | --- |
| Variable name | **`BOARD`** ← 대문자로 정확히 |
| KV namespace | **`board`** (1번에서 만든 것) |

4. **Deploy**

## 5. 비밀번호 정하기

1. 같은 **Settings** → **Variables and Secrets** → **Add**
2. Type: **Secret**
3. 이렇게 두 개를 넣습니다

| Variable name | Value |
| --- | --- |
| **`BOARD_PASSWORD`** | 공유할 비밀번호 (이걸 팀원에게 알려줍니다) |
| **`TOKEN_SECRET`** | 아무 긴 무작위 문자열 (아무도 몰라도 됨) |

`TOKEN_SECRET` 은 키보드를 마구 두드린 30자 이상이면 됩니다. 예: `k3j2n4kj2h34kjh234kjh2k3j4h2k3j4h`

4. **Deploy**

## 6. 주소 복사

Worker 화면 위쪽에 주소가 있습니다.

```
https://board.<본인계정이름>.workers.dev
```

## 7. 앱에 등록

1. https://by.phb.kr 접속
2. **⚙ 설정** → **공유 서버**
3. 주소를 붙여넣고 **연결 확인** → "서버가 응답했습니다" 가 뜨면 **저장**
4. 화면이 새로고침되고 비밀번호를 묻습니다. **5번에서 정한 `BOARD_PASSWORD`** 를 넣으세요
5. 이름도 함께 넣으면 누가 고쳤는지 표시됩니다

## 8. 기존 내용 올리기 (한 번만)

서버는 처음엔 비어 있습니다. PC에 있던 내용을 올려야 합니다.

1. 로그인한 뒤 **⚙ 설정** → **백업 파일 불러오기**
2. 받아 두신 백업 파일 선택

불러오면 자동으로 서버에 올라갑니다. 이제 다른 사람이 들어와도 같은 내용이 보입니다.

---

## 팀원에게 알려줄 것

```
주소:      https://by.phb.kr
비밀번호:  (BOARD_PASSWORD 에 정한 값)
```

팀원은 들어가서 비밀번호와 이름만 넣으면 됩니다. **아무 설정도 필요 없습니다** — 서버 주소는 `js/remote.js` 의 `DEFAULT_BASE` 에 적혀 있습니다.


---

## 알아 둘 것

**동시에 같은 곳을 고치면** 나중에 저장한 쪽이 남습니다. 서버가 버전을 확인해서 모르게 덮어쓰는 일은 막고, 최신 내용을 받아와 화면을 맞춘 뒤 알려 줍니다. 밀린 쪽의 마지막 몇 초치 입력은 사라질 수 있습니다.

서로 다른 항목을 고치는 보통의 상황에서는 문제가 없습니다.

**화면 갱신은 20초마다** 확인합니다. 상대가 고친 내용이 바로 뜨지는 않고, 최대 20초 정도 걸립니다. 다른 탭에 가 있는 동안에는 확인하지 않고, 돌아오면 바로 한 번 확인합니다.

**무료 범위**는 하루 읽기 10만 건, 쓰기 1천 건입니다. 몇 사람이 쓰는 정도로는 넉넉합니다.

**백업은 계속 받아 두세요.** 서버에 있다고 안전한 건 아닙니다. ⚙ 설정 → 백업 파일 내려받기.

## 잘 안 될 때

| 증상 | 해결 |
| --- | --- |
| "KV 저장소(BOARD)가 연결되지 않았습니다" | 4번을 안 했거나 Variable name 이 `BOARD` 가 아닙니다 |
| "비밀번호(BOARD_PASSWORD)가 설정되지 않았습니다" | 5번을 안 했습니다 |
| "허용되지 않은 주소에서의 요청입니다" | `board-worker.js` 위쪽 `ALLOWED_ORIGINS` 에 지금 쓰는 주소가 없습니다 |
| "서버에 닿지 못했습니다" | 주소 오타이거나 Deploy 를 안 눌렀습니다 |
